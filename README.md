# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Python.

The main goal of this project is to understand sales, profit,
products, categories, regions, and monthly sales performance.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

│
├── main.py

## Analysis Performed

- Dataset inspection
- Missing value analysis
- Duplicate value analysis
- Statistical analysis
- Total sales calculation
- Total profit calculation
- Product-wise sales analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Monthly sales analysis
- Product-wise profit analysis

## Visualizations

- Sales by Product
- Sales by Category
- Sales by Region
- Profit by Product

## Key Insights

- Laptop is the top-selling product.
- Laptop is the most profitable product.
- Electronics is the largest sales category.
- North region has the highest sales.
- March has the highest monthly sales.

## Conclusion

This project demonstrates how Python can be used to
analyze e-commerce sales data and extract useful
business insights.
